## Instrucciones de Generación

1. Usa el prompt completo tal cual está escrito
2. Añade `--ar 16:9` para paisajes (portada, escenas)
3. Añade `--ar 1:1` para retratos
4. Estilo recomendado: "Expedition 33 aesthetic, dark fantasy, cinematic lighting, highly detailed"
5. Para Midjourney, añade `--v 6` o `--v 5.2`
6. Para DALL-E 3, usa el prompt completo sin modificadores
7. Para Stable Diffusion, usa el modelo "DreamShaper" o "RealisticVision" con CFG 7-8

## Referencias en Markdown

Una vez generadas las imágenes, actualiza los archivos markdown con:

```markdown
![Descripción](imagenes/nombre-archivo.png)
```

Ejemplos de ubicación:
- Portada: `acts/actos.md` - inicio del documento
- Vorathrax: `bestiary/bestiary.md` - sección Vorathrax
- Retratos NPC: `npcs/npcs.md` - secciones respectivas
- Escenas: `maps/maps.md` o `acts/actos.md` - escenas relevantes
